# 整体 UI 收尾验收清单

本文档用于统一验收当前系统的 UI 收尾质量。目标不是重新设计页面，而是在现有满意样板基础上，检查页面容器、卡片、表格、弹窗、抽屉、状态反馈等是否稳定一致。

## 验收基准

当前视觉样板以以下页面为准：

- 系统设置：AI 连接、空间配置等设置类页面。
- 配置中心：环境配置、参数配置、数据库连接。
- 接口自动化：执行 tab。

验收时优先保证这些页面的视觉语言不被破坏，再让其他页面向它们靠齐。

## 优先级定义

- P0：明显影响使用或破坏页面结构，例如内容被遮挡、不能滚动、按钮不可见、弹窗无法关闭。
- P1：明显视觉不一致，例如表格行高差异很大、弹窗样式不同、卡片阴影过重、间距失衡。
- P2：细节优化，例如 hover 状态、弱提示文案、边框颜色、空状态插画风格。

## 全局验收项

### 页面布局

- [ ] 页面主容器外边距统一，不同模块切换时没有明显跳变。
- [ ] 页面标题、描述、右侧操作按钮位置稳定。
- [ ] section 之间间距统一，不能有过大的空白或挤压。
- [ ] 页面内容不足一屏时保持舒展，不贴边、不坍缩。
- [ ] 页面内容超过一屏时滚动区域正确，固定头部或底部不会遮挡内容。
- [ ] 不出现横向滚动，除非是表格自身横向滚动。

### 卡片与分割线

- [ ] 普通卡片统一使用浅边框、轻阴影、白底。
- [ ] 重点卡片可以略强阴影，但不能压过页面层级。
- [ ] 卡片圆角统一，避免同一页面出现多个圆角体系。
- [ ] 卡片 header 与 body 的 padding 统一。
- [ ] 分割线颜色偏浅，只承担分区作用，不抢视觉。
- [ ] 表格、弹窗、抽屉里的分割线和页面卡片分割线风格一致。

### 表格

- [ ] 表头字体、颜色、背景、边框一致。
- [ ] 行高一致，内容不会被压扁或过度撑高。
- [ ] 操作列宽度稳定，固定列滚动时不会残留标题或错位。
- [ ] 分页区域高度、边框、按钮样式一致。
- [ ] 空数据、加载中、错误状态都使用统一反馈样式。
- [ ] 长文本有合理省略、换行或详情入口，不撑破布局。

### 表单

- [ ] 输入框、选择框、textarea 高度和圆角一致。
- [ ] label、必填标记、帮助文本、错误提示位置一致。
- [ ] 长 prompt 或长文本区域有固定高度和内部滚动，不挤压页面。
- [ ] 表单分组之间间距清晰，不出现字段贴得太近或太散。
- [ ] disabled、loading、校验失败状态清晰可见。

### 按钮与操作入口

- [ ] 主按钮、次按钮、文字按钮、危险按钮层级清晰。
- [ ] 图标按钮有稳定尺寸、hover 状态和可识别含义。
- [ ] 列表行内操作不会过密，危险操作有确认。
- [ ] loading 时按钮状态明确，避免重复提交。
- [ ] 同一页面不混用多套按钮尺寸。

### 弹窗与抽屉

- [ ] 弹窗 header、body、footer 层级清楚。
- [ ] 弹窗底部操作按钮位置统一，主操作靠右。
- [ ] 抽屉标题、描述、tab、内容区不会互相遮挡。
- [ ] 抽屉内容可滚动，tab 或 header 固定时边界线可见。
- [ ] 弹窗和抽屉的遮罩、阴影、圆角统一。
- [ ] 成功、失败、校验提示不会被遮罩或弹窗层级挡住。

### 标签、状态与统计

- [ ] P0/P1/P2、任务状态、评审状态、供应商标签使用统一色彩语言。
- [ ] 同一个语义在不同页面命名一致，例如供应商名称不混用中文/英文。
- [ ] 统计数字字体、颜色、单位、辅助描述一致。
- [ ] 状态不只依赖颜色，必要时有文字说明。

### 空状态、加载态、错误态

- [ ] 页面建设中、暂无数据、正在加载、接口失败使用统一样式。
- [ ] 切换 tab 或进入页面时不闪现错误的空状态。
- [ ] 加载态保留页面基本结构，减少布局跳动。
- [ ] 错误态提供可执行动作，例如重试、去配置、刷新。

### 响应式与浏览器尺寸

- [ ] 1366x768 下核心内容可用，不被底部或侧边遮挡。
- [ ] 1920x1080 下内容不会过散，卡片宽度有上限或合理栅格。
- [ ] 窄屏下多列卡片可降为单列或两列。
- [ ] 抽屉和弹窗在小屏下仍可滚动并完成操作。

## 模块验收清单

### 工作台

- [ ] 占位页面样式与其他建设中页面一致。
- [ ] 页面标题、空状态、说明文案居中且不突兀。

### 用例中心

- [ ] 用例管理列表、筛选区、分页区样式统一。
- [ ] 用例详情抽屉 tab 切换不抖动，内容滚动正常。
- [ ] 新建/编辑用例弹窗或抽屉与全局样式一致。
- [ ] 用例执行页轻量统一后，标题、卡片、状态、操作按钮一致。
- [ ] AI 配置页卡片不被长 prompt 挤压，textarea 内部滚动正常。
- [ ] AI 生成记录列表、详情页、实时输出板状态清晰。

### 缺陷管理

- [ ] 缺陷列表列高、字段展示、操作列与 Figma/样板一致。
- [ ] 新建/编辑页面表单区域层级清楚。
- [ ] 详情页信息卡、时间线、附件、关联区域间距统一。
- [ ] 关联弹窗/抽屉样式与全局弹窗/抽屉一致。

### 接口自动化

- [ ] 执行 tab 保持当前满意样式。
- [ ] 报告和设置 tab 使用统一占位页。
- [ ] 用例、步骤、参数、断言、处理器编辑区样式统一。
- [ ] 表格和编辑器区域高度稳定，不挤压主要内容。
- [ ] 弹窗、抽屉、快速提取入口视觉一致。

### 配置中心

- [ ] 左侧分类、右侧内容区与当前满意样式一致。
- [ ] 环境配置、参数配置、数据库连接列表和弹窗一致。
- [ ] 新增/编辑/删除/测试连接等操作反馈统一。

### 系统设置

- [ ] 左侧设置分类和右侧内容区保持 Figma 风格。
- [ ] AI 连接池卡片、统计、供应商网格、弹窗样式一致。
- [ ] 空间配置列表、成员管理、新增工作空间弹窗一致。
- [ ] 未实现分类统一展示建设中占位页。

## 推荐验收顺序

1. 先验收系统设置、配置中心、接口自动化执行 tab，确认样板页面没有被全局样式影响。
2. 再验收用例中心和缺陷管理，因为它们页面最多、状态最多。
3. 最后验收工作台、Web UI 自动化、APP 自动化等占位页。
4. 每发现一个问题，按 P0/P1/P2 记录，不同问题分开修，避免一次改动影响过大。
